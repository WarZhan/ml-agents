# Project 类图（Unity 端 Examples）

> 本文件用 Mermaid 类图描述 `Project/Assets/ML-Agents/Examples` 下各 Demo 的类结构与关系。
> 为便于阅读，按子系统拆分成多张图。带 `«ML-Agents»` 标注的为 ML-Agents SDK/扩展包提供的基类，其余为示例工程自有类。
>
> 关系约定：`<|--` 继承 / 实现；`-->` 持有引用（关联）；`..>` 依赖/调用。

---

## 1. 总览：Agent 继承体系

所有可训练脚本都继承自 ML-Agents 的 `Agent`（其本身是 Unity 的 `MonoBehaviour`）。

```mermaid
    note for BasicController "Basic 示例不继承 Agent，改用自定义 Sensor/Actuator 组件接入"
```

## 2. Basic：自定义 Sensor / Actuator（无侵入接入）

演示不继承 `Agent`，通过组件式传感器/执行器把普通 `MonoBehaviour` 接入 ML-Agents。

```mermaid
classDiagram
    class MonoBehaviour
    class SensorComponent {
        <<ML-Agents>>
        +CreateSensors()
    }
    class ActuatorComponent {
        <<ML-Agents>>
        +CreateActuators()
    }
    class ISensor {
        <<ML-Agents 接口>>
    }
    class IActuator {
        <<ML-Agents 接口>>
    }
    class SensorBase {
        <<抽象>>
        +WriteObservation(float[])
        +GetObservationSpec()
        +GetName()
    }

    ISensor <|.. SensorBase
    SensorBase <|-- BasicSensor
    SensorComponent <|-- BasicSensorComponent
    ActuatorComponent <|-- BasicActuatorComponent
    IActuator <|.. BasicActuator

    MonoBehaviour <|-- BasicController

    BasicSensorComponent --> BasicController
    BasicSensorComponent ..> BasicSensor : creates
    BasicActuatorComponent --> BasicController
    BasicActuatorComponent ..> BasicActuator : creates
    BasicSensor --> BasicController
    BasicActuator --> BasicController : MoveDirection()
```

## 3. 关节角色运动（Crawler / Worm / Walker）

三个角色共享 SharedAssets 的关节驱动核心 `JointDriveController` + `BodyPart`，
并使用稳定参考系 `OrientationCubeController` 与朝向指示 `DirectionIndicator`。

```mermaid
classDiagram
    class Agent { <<ML-Agents>> }
    class MonoBehaviour

    class JointDriveController {
        +maxJointSpring
        +jointDampen
        +maxJointForceLimit
        +bodyPartsDict : Dictionary~Transform,BodyPart~
        +bodyPartsList : List~BodyPart~
        +SetupBodyPart(Transform)
    }
    class BodyPart {
        +joint : ConfigurableJoint
        +rb : Rigidbody
        +groundContact : GroundContact
        +targetContact : TargetContact
        +SetJointTargetRotation(x,y,z)
        +SetJointStrength(strength)
        +Reset(BodyPart)
    }
    class OrientationCubeController
    class DirectionIndicator
    class GroundContact
    class TargetContact

    MonoBehaviour <|-- JointDriveController
    JointDriveController "1" --> "*" BodyPart : manages
    BodyPart --> GroundContact
    BodyPart --> TargetContact
    BodyPart --> JointDriveController : thisJdController

    Agent <|-- CrawlerAgent
    Agent <|-- WormAgent
    Agent <|-- WalkerAgent

    CrawlerAgent --> JointDriveController
    WormAgent --> JointDriveController
    WalkerAgent --> JointDriveController
    CrawlerAgent --> OrientationCubeController
    WalkerAgent --> OrientationCubeController
    CrawlerAgent --> DirectionIndicator
    WalkerAgent --> DirectionIndicator
```
